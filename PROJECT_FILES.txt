ARCHITECTURE HIGHLIGHTS
-----------------------
- Service Layer Abstraction: All data persistence in isolated api.js
- Async/Await Interface: Easy swap from localStorage to HTTP backend
- Component Composition: Modular, reusable React components
- Unidirectional Data Flow: Props down, callbacks up
- Hook-based State Management: Modern React patterns
- Canvas Transformer Pattern: Select, drag, resize, rotate
- Event-driven Google Maps Integration: Real-time position/POV updates
- Mock Network Latency: Realistic testing with localStorage

USAGE WORKFLOW
--------------
1. Navigate map/Street View → Find location
2. Capture view → Lock position and angle
3. Add assets from library → Click to place on canvas
4. Transform assets → Drag, resize, rotate as needed
5. Compare before/after → Interactive slider
6. Fill metadata → Title, description, problems, solutions
7. Save imagination → Persisted to localStorage
8. Share → Export as JSON file
